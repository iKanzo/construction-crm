# Тестирование

Инструкции по окружению и ограничения тестовых данных приведены в [DEVELOPMENT.md](DEVELOPMENT.md). Ниже перечислены предусмотренные команды, а не результаты их выполнения.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
npm run db:start
npm run test:db
npm run db:stop
```

Frontend использует Vitest и React Testing Library; браузерные тесты — Playwright. SQL-тесты в `tests/backend/database` используют pgTAP и проверяют структуру, ограничения, триггеры, RLS, привилегии и отдельные регрессии RPC. `npm run test:db:local` — альтернативный раннер для отдельного локального PostgreSQL с pgTAP: он пересоздаёт тестовую базу, поэтому сначала изучите [инструкцию](DEVELOPMENT.md).

Имеющиеся браузерные smoke-тесты не заменяют сценарии авторизации и бизнес-операций. Для приёмки необходимо дополнить и выполнить ролевые сценарии, тесты передачи, деактивации, конкурентных запросов и Edge Function приглашения, а также проверить production build и CI. Само наличие тестового файла не подтверждает успешную проверку.

`npm run db:reset` удаляет все данные локальной базы; не применяйте эту команду к данным, которые необходимо сохранить. Локальный seed предназначен только для разработки и не должен использоваться в рабочем окружении.
